# Framer Agent handoff

## Goal
Build the Clinica AI healthcare technology website as a native, editable Framer project. This repository is the planning/source companion; it is not itself a native Framer project.

## Setup command requested by project owner
```bash
npx @framer/agent@latest setup
```

Run only after confirming Node.js/npm availability, reviewing the current official Framer Agent instructions, and authenticating the correct Framer account/project. Do not expose access tokens in logs, source files or commits.

## Build constraints
- Native Framer layers/components and CMS are the deliverable.
- Do not substitute a static HTML export for a native Framer project.
- Build each section at desktop, tablet and phone before moving to the next.
- Capture and inspect screenshots after each section.
- Never claim a test or screenshot was performed unless it actually was.
- Do not fabricate patient data, clinical evidence, outcomes, metrics, logos, certifications or regulatory status.
- Keep all demo/sample data visibly labelled.
- Preserve a rollback point before major edits.
