## Content integrity

All company names, product descriptions and interface examples in this template are fictional placeholders for the template buyer to customize. Do not add fabricated clinical outcomes, patient testimonials, regulatory certifications, customer logos, usage numbers or performance claims. Clearly label any illustrative interface data as sample/demo data.

## Build principle

Design every section for desktop, tablet and phone together. After each section, capture screenshots at all three breakpoints, inspect layout and interaction, fix issues, then proceed.
