# Responsive QA checklist

For every page and every section, test all three breakpoints before continuing.

## Desktop
- [ ] No horizontal overflow.
- [ ] Content aligns to max-width grid.
- [ ] Navigation and dropdowns work.
- [ ] Text measure and line breaks are intentional.
- [ ] Cards and media have consistent alignment.

## Tablet
- [ ] Navigation adapts without collisions.
- [ ] Multi-column grids reflow cleanly.
- [ ] Images crop without losing essential subject.
- [ ] Buttons and forms remain comfortably usable.
- [ ] No fixed-width element causes overflow.

## Phone
- [ ] Mobile menu opens, closes and is keyboard accessible.
- [ ] Single-column content order is logical.
- [ ] No clipped headings or buttons.
- [ ] Tap targets are comfortably sized.
- [ ] Forms fit viewport and show labels/errors.
- [ ] Sticky UI does not obscure content.
- [ ] Images and diagrams remain legible.

## Evidence
- [ ] Desktop screenshot captured and reviewed.
- [ ] Tablet screenshot captured and reviewed.
- [ ] Phone screenshot captured and reviewed.
- [ ] Defects recorded and retested.
