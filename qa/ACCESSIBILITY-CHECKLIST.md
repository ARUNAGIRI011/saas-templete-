# Accessibility QA checklist

- [ ] Semantic landmarks and one clear H1 per page.
- [ ] Heading hierarchy is logical.
- [ ] All controls work using keyboard only.
- [ ] Focus indicator is visible and not obscured.
- [ ] Mobile menu and dialogs manage focus correctly.
- [ ] Inputs have persistent labels and understandable errors.
- [ ] Link text is descriptive outside context.
- [ ] Images have appropriate alt text or are decorative.
- [ ] Contrast is checked for text, controls and states.
- [ ] Status is not communicated by colour alone.
- [ ] Motion respects prefers-reduced-motion.
- [ ] Video has controls/captions where applicable.
- [ ] CMS empty/error states are understandable.
- [ ] Final review with automated and manual checks is recorded.
