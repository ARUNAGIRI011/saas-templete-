# Marketplace listing draft

## Title
Clinica AI — Healthcare AI SaaS Website

## Short description
A calm, modern Framer website template for healthcare AI, clinical workflow and medical technology companies. Includes responsive marketing pages, reusable sections and CMS-ready resource layouts.

## Planned page list
Home, Platform, Clinical Workflows, Healthcare Analytics, Research, Security & Privacy, Integrations, Pricing, Resources, Blog Detail, About, Contact and 404.

## Planned highlights
- Healthcare-specific content architecture
- Responsive desktop, tablet and phone layouts
- Reusable navigation, cards, CTA and FAQ components
- CMS-ready articles, use cases, research and integrations
- Clear human-oversight and trust-content sections
- Editable typography, colour and spacing tokens
- Customization guide and accessible interaction patterns

Only advertise features that are implemented and tested in the final Framer project.

## Five thumbnail concepts
1. **Hero overview:** Full home hero with navigation, headline and product visual.
2. **Page gallery:** Clean grid showing home, platform, security and pricing pages.
3. **Workflow showcase:** Large workflow illustration with feature callouts.
4. **Responsive proof:** Desktop, tablet and phone mockups of the same page.
5. **CMS and components:** Resource cards, use-case collection and reusable component examples.

## Listing QA
- Confirm every advertised page exists.
- Confirm all links and interactions work.
- Confirm CMS collections are populated with clearly fictional sample content or buyer-ready blanks.
- Confirm mobile screenshots are genuine.
- Confirm license, fonts, assets and external dependencies are documented.
- Confirm no false clinical, compliance, customer or performance claims.
