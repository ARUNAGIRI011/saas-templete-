# Sitemap and page requirements

## Core pages
1. **Home** — positioning, workflow overview, capabilities, trust approach, CTA.
2. **Platform** — product architecture, data flow, deployment options and human oversight.
3. **Clinical Workflows** — configurable workflow examples; clearly state illustrative status.
4. **Healthcare Analytics** — data exploration, reporting and operational insights.
5. **Research** — evidence principles, publication/resource index and methodology placeholders.
6. **Security & Privacy** — security practices, data lifecycle, access controls and compliance placeholders.
7. **Integrations** — integration categories and implementation approach; no invented partner logos.
8. **Pricing** — configurable plans or “Talk to sales”; avoid invented real-world prices if buyer has not supplied them.
9. **Resources** — CMS index for articles, guides and research notes.
10. **Blog detail** — CMS template.
11. **About** — mission, team placeholders and responsible AI principles.
12. **Contact / Demo request** — form layout with explicit integration setup note.
13. **404** — helpful recovery navigation.

## CMS collections
- **Articles:** title, slug, summary, body, category, author, publish date, cover image, reading time (manual value, not fabricated).
- **Use cases:** title, slug, audience, challenge, workflow, oversight notes, illustrative diagram, CTA.
- **Research/resources:** title, slug, type, abstract, publication date, external URL, author/source.
- **Integrations:** name, category, description, status label, logo/image supplied by buyer, documentation URL. Do not imply an integration exists unless verified.

## Navigation
Platform | Solutions | Resources | Company | Pricing | Request a demo

## Footer
Product navigation, resource links, company links, contact, privacy/legal placeholders and social links supplied by buyer.

## Shared sections
Announcement bar (optional), responsive header, hero, trust principles, workflow steps, feature grid, product preview, CTA band, FAQ, footer and cookie/privacy notice where legally required.
